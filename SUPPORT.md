# Getting Support for cur8d

Welcome to the cur8d community! Here are the best ways to get help and support:

## Documentation

Comprehensive documentation, stack architecture overviews, and quick start guides are available at [cur8d.dev](https://cur8d.dev).

## Asking Questions & Community Discussion

For general questions, discussions, architecture advice, or ideas:

- Join the discussion on [cur8d GitHub Discussions](https://github.com/orgs/cur8d/discussions).

## Bug Reports & Feature Requests

- If you found a bug or want to suggest a new feature, search the repository's issue tracker first to avoid duplicates.
- Submit a detailed report using our [Bug Report Form](https://github.com/cur8d/.github/issues/new?template=bug_report.yml) or [Feature Request Form](https://github.com/cur8d/.github/issues/new?template=feature_request.yml).

## Security Reports

Please do **not** report security vulnerabilities via public issues. See our [Security Policy](SECURITY.md) for private disclosure instructions.
