## Quick Start

Scaffold any template instantly using the [`create-cur8d`](https://github.com/cur8d/create-cur8d) CLI:

```bash
npx create-cur8d
```

Or target a specific template:

```bash
# TypeScript / Next.js web application
npx create-cur8d --template tsx my-app

# Production-ready Python project
npx create-cur8d --template py my-project

# AWS Lambda microservice
npx create-cur8d --template lambda my-service
```
