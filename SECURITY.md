# Security Policy

## Supported Versions

We actively support and provide security updates for the latest released versions of each template and package in the `cur8d` ecosystem.

| Project | Supported |
| :--- | :--- |
| `cur8d/typescript` | :white_check_mark: |
| `cur8d/cur8d.github.io` | :white_check_mark: |
| `cur8d/python` | :white_check_mark: |
| `cur8d/lambda` | :white_check_mark: |
| `cur8d/create-cur8d` | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within any `cur8d` repository, please do **not** open a public issue.

Instead, please report security vulnerabilities via:
- GitHub Security Advisory reporting on the affected repository
- Or by emailing security concerns directly to the organization maintainers

We will acknowledge receipt within 48 hours and coordinate a coordinated disclosure and patch.
